## 🎯 Project Overview

This repository contains a professional, conversion-focused landing page for the manufacturing sector. It eliminates unnecessary bloat (no 3D rendering libraries) to focus on **Subtractive Manufacturing** (Milling, Turning, and Custom Solutions), ensuring the fastest possible load times for industrial B2B leads.

## 🚀 SEO Strategy

This project is built with a **"Search Engine First"** mindset to help manufacturing businesses rank higher:

*   **TDK Optimization**: Hand-crafted Title, Description, and Keywords focused on `CNC Machining`, `Precision Milling`, and `Industrial Parts`.
*   **Semantic HTML5**: Uses `<header>`, `<main>`, `<section>`, and `<article>` to help Google understand content hierarchy.
*   **Zero Jargon Dilution**: Purely focused on traditional CNC services—no 3D printing or additive manufacturing keywords to maintain high niche relevancy.
*   **Structured Data Ready**: Includes a technical specification table that search engines can use for "rich snippets."

## ✨ Key Features

-   **Image Fix Applied**: Optimized CSS using `object-fit: contain` to ensure technical parts photos are never cropped or distorted.
-   **Service-Oriented CTAs**: Strategically placed outbound links targeting high-value service pages:
    -   [CNC Milling Services](https://ms-machining.com/cnc-milling/)
    -   [CNC Turning Services](https://ms-machining.com/cnc-turning-finishes/)
    -   [5-Axis Solutions](https://ms-machining.com/5-axis-machining-services/)
-   **Responsive Design**: Fully compatible with desktop, tablet, and mobile devices.
-   **Clean UI**: Industrial-grade aesthetic using the `Inter` font stack and a professional Slate/Blue color palette.

## 🛠 Technical Stack

| Component | Technology | Benefit |
